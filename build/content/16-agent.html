Vom Ratgeber zum Handelnden.

Bis hierhin hat Ihre Assistenz geantwortet. Ein Agent tut etwas — und läuft so lange, bis das Ziel erreicht ist.

Generative KI · beratend
  1. Sie stellen eine Frage
  2. Es entsteht genau eine Antwort
  3. Fertig. Danach ist nichts anders.
„Schreiben Sie mir eine Notiz zum Kundengespräch.“
Agent · handelnd
  1. Sie geben ein Ziel, keine Einzelaufgabe
  2. Planen → handeln → nachschauen → wieder von vorn
  3. Danach ist etwas anders — Mails, Termine, Dateien
„Bereiten Sie die nächste Stiftungsratssitzung vor.“

Der Unterschied ist nicht Klugheit. Der Unterschied ist Folgenlosigkeit — links kann nichts passieren, rechts schon. Deshalb wird rechts geprüft, bevor etwas rausgeht.
