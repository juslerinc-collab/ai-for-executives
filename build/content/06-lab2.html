Hands-on · Lab 2 · Aufsetzen

Das leere Blatt.

Standardaufgabe — oder Ihr eigenes leeres Blatt, das Sie schon vor sich herschieben.
Schreiben Sie eine Auftragsbestätigung an eine neue Kundschaft in der {{Branche}} — professionell, aber persönlich, wie bei {{Firma}} üblich. Inklusive grobem Kostenrahmen als einfache Tabelle im Text, zwei bis drei Positionen, keine Details.
Der Kostenrahmen bleibt einfacher Text/Tabelle in der Mail — kein echtes Excel, das wäre schon Aufbereiten.
Die Absage, die Sie seit Tagen vor sich herschieben (E-Mail)
„Schreiben Sie eine freundliche, aber klare Absage an [Anbieter/Bewerberin] … kurz, ohne lange Begründung, aber nicht kalt.“
Ein erster Entwurf für die Vorstandsvorlage (Dokument)
„Schreiben Sie einen ersten Entwurf für eine Vorstandsvorlage zu [Thema] — Ausgangslage, Empfehlung, nächste Schritte, eine halbe Seite.“
Die Agenda für ein schwieriges Gespräch (Struktur/Liste)
„Erstellen Sie eine Agenda für ein Gespräch mit [Person/Team] … die drei wichtigsten Punkte, plus ein Vorschlag, wie ich es eröffne.“
Eine Bild-Instruktion für ein erstes visuelles Konzept
„Beschreiben Sie mir ein Bildkonzept für [Anlass] — Stil, Farbwelt, was im Vordergrund steht, damit ich es instruieren kann.“
Das Grusswort, das jemand von Ihnen erwartet (Rede/Text)
„Schreiben Sie ein kurzes Grusswort für [Anlass] — persönlich, kurz genug zum Vorlesen.“
Ton & Zielgruppe
„… professionell, aber persönlich, wie bei {{Firma}} üblich.“
Struktur
„Gliedern Sie die E-Mail in drei Teile: Rückblick auf das Gespräch, nächste Schritte, ein grober Kostenrahmen.“
Rahmenbedingungen
„Maximal eine halbe Seite. Der Kostenrahmen erscheint als einfache Tabelle mit zwei bis drei Positionen, keine Details.“
Referenz
„Orientieren Sie sich am Ton dieser früheren E-Mail an eine Kundin: [Beispieltext einfügen].“
Abschluss
„Schließen Sie mit einem konkreten nächsten Schritt — ein Termin zur Bestätigung, keine offene Frage.“
