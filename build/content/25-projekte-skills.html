Damit sie nicht jedes Mal bei null anfängt.

Bisher haben Sie jedes Gespräch neu ausgestattet. Zwei Einrichtungen nehmen Ihnen das ab — und beide bauen Sie aus etwas, das Sie ohnehin schon zweimal getippt haben.

Projekt — der Raum
Was es ist
Ein eigener Raum für ein Thema. Sie legen Unterlagen hinein und eine Dauer-Instruktion dazu.
Was hineingehört
Ihre Rolle, Ihr Haus, Ihr Ton — und die zwei, drei Dokumente, die Sie immer wieder brauchen.
Was es bringt
Jedes neue Gespräch darin startet vorbereitet. Prinzip 2, dauerhaft eingerichtet.
Beispiel
Ein Projekt „Stiftungsrat“ mit Reglement, den letzten drei Protokollen und einer Zeile zum Ton.
Skill — das Verfahren
Was es ist
Eine benannte Arbeitsanweisung für eine wiederkehrende Aufgabe. Einmal geschrieben, jedes Mal gleich abgerufen.
Was hineingehört
Die Schritte, das gewünschte Format, die Grenzen — so, wie Sie es einer neuen Assistenz einmal erklären würden.
Was es bringt
Sie sagen nur noch den Namen. Prinzip 1, konserviert statt jedes Mal neu formuliert.
Beispiel
Ein Skill „Protokoll zu Traktandenliste“ — genau das, was Sie in Lab 3 von Hand instruiert haben.

Das Projekt sagt wo gearbeitet wird, der Skill sagt wie. Faustregel: Was Sie zum dritten Mal tippen, gehört in eines von beiden.
