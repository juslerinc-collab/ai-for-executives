# Charting session decisions

Type: grilling
Status: resolved

## Question

What is settled before the map opens — the decisions made during the charting conversation itself.

## Answer

**Destination.** A locked build spec, not a shipped page and not content-only. The three layers interlock, so settling one without the others locks it against a format not yet chosen.

**The artifact.** A click-through HTML site: PowerPoint-like navigation plus a section menu, but slides that carry real content. Explicitly not a PowerPoint, and explicitly not the brief's "three lines per slide" deck — that constraint existed to stop an audience reading ahead of a speaker, which does not apply at a desk with one person. Works live with the facilitator and alone afterward.

**Reusable, not one-off.** Content stays generic; the supplied lab assets do the work. This executive is instance one.

**Audience, sharpened.** Has poked at ChatGPT. Wants foundation, daily leverage, and use cases inside their company. This replaces the brief's "quietly does not want to look foolish" framing — less anxious, more opportunity-seeking. Vendor-neutral framing matters more because they arrive with ChatGPT habits.

**Language.** German, including the copy-ready prompts.

**Where the AI happens.** In the executive's own Claude window, open in parallel with the page. The page supplies copy buttons. No embedded chat and no API — they practise in the tool they will actually open on Monday, and the window-switching is part of the skill.

**Exception:** the final use-case section runs inside the page itself as an interactive component — capture, place on an impact-vs-effort matrix, produce a ranked backlog.

**Delivery.** Authored as multiple files, built into one self-contained HTML file with assets inlined as base64. That single file is both the handover artifact and the thing that gets hosted. Hosting is a later, cheap decision — noted: GitHub Pages cannot password-protect, and a password baked into static HTML is bypassable via view-source.

**Content flow, reshaped.** Accepted against the brief's four-block structure:

1. Open with a hands-on win inside the first ten minutes, before any theory.
2. Compress brief lessons 1, 2 and 3 into a single basics lesson.
3. Move the ladder of autonomy earlier — right after the first win, as the map of the day.
4. **Data lab stays** (rejected proposal to cut it). Reframed: not "you will clean spreadsheets" but "look what this can do, and note how many people in your company do this by hand." It feeds the organizational lens.
5. Split risk/governance — "what not to paste" moves to one line before Lab 1; judgment folds into the closing.
6. The backlog builds itself. Every lab debrief's third question drops a card into the use-case backlog, so the final matrix section sorts eight cards the executive generated over three hours instead of starting from a blank page.

**New lesson: the sweet spot.** A lesson naming what today's AI is genuinely strong at, with a real example each — comparing, combining, reconciling, summarising, extracting, drafting. Its patterns become the shared vocabulary of the whole session: every lab announces which pattern it is, every debrief card is tagged with one, and the same patterns are the categories in the final matrix.
