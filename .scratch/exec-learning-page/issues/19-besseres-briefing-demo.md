## Answer

**Task:** eine Einladung zu einem internen Workshop schreiben. Chosen to be distinct from both labs' default tasks (Lab 1's "Erklären Sie mir Claude," Lab 2's client-engagement email) so nothing repeats across the session.

**Four runs — revised 2026-07-27, back to four after a brief detour through "replace run 3":**

| Durchlauf | Prompt |
|---|---|
| 1. Faul | *„Schreib eine Einladung zu einem Workshop."* |
| 2. Mit Kontext | *„Schreiben Sie eine Einladung zu einem internen Workshop zum Thema [X] für [Zielgruppe], am [Datum], Dauer [Y] Stunden — Ziel ist [Z]."* |
| 3. Mit Beispiel | Wie 2, plus: *„Hier ist eine frühere Einladung, die gut ankam: [Beispieltext] — orientieren Sie sich am Ton."* |
| 4. Claude briefen lassen | *„Ich möchte eine Einladung zu einem internen Workshop schreiben. Wie sollte ich Sie am besten briefen, damit das Ergebnis gut wird?"* — Claude schlägt eine Struktur vor oder fragt gezielt nach; das Ergebnis wird direkt verwendet. |

**Closing line:** *„Sie müssen die perfekte Anfrage nicht selbst kennen — fragen Sie danach."* Also quietly previews Aufsetzen (rows 5–6 use exactly this instinct) without stealing their thunder.

**Time note:** four runs may not fit the row's original 10-minute allocation as comfortably as three did — flag this to [The lesson sequence](01-lesson-sequence.md) if it needs a minute or two more, borrowed from the ~29-min buffer noted there.
